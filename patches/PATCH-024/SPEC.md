# PATCH-024 — OpenAI TTS: выбор голоса и восстановление речи

Статус: **локальный build 30 кандидат; ещё не установлен**.

## Цель

Дать человеку явный выбор OpenAI для озвучивания. Сейчас раздел предлагает общий
«Свой сервер синтеза», хотя для него нужны вручную введённые URL, модель и имена
голосов. Перепутанное имя голоса персонажа с именем голоса другого TTS сервера
может привести к отказу синтеза.

## Поведение

- Кнопка «Выбрать OpenAI TTS API» задаёт `https://api.openai.com/v1`,
  `gpt-4o-mini-tts`, 24 кГц и голоса `nova`/`onyx`; затем человек сам вводит
  свой OpenAI API key в поле ключа.
- Кнопка не отправляет запрос и не включает голос без явного выбора `remote`.
  Запросы синтеза используют OpenAI API и могут тарифицироваться согласно
  настройкам аккаунта API.
- При OpenAI preset приложение не передаёт дополнительные параметры сервера
  (например, `language`) и не подставляет голос персонажа из чужого движка.
- Если синтез или вывод звука недоступен, подтверждение фактического
  воспроизведения требует отдельного прогона на устройстве с разрешённым звуком.

## Тестовый контракт

- Mock HTTP проверяет endpoint, модель, голос, удаление чужого голоса персонажа,
  отсутствие proxy-only `extra` и PCM-поток. В тесте ноль сетевых обращений за
  пределы loopback и ноль расходов.
- Browser UI smoke проверяет наличие кнопки и применение настроек;
  регрессионные проверки выбора модели/провайдера и переключателей голоса
  выполняются отдельно.
- На реальном ПК нужен ручной выбор OpenAI в настройках, ввод личного API key,
  тестовая фраза и проверка вывода через выбранное устройство. До этого live
  голос отмечается **NOT_RUN**.

## Откат

Удалить кнопку и её обработчик; вернуть прежнюю сборку `RemoteTTS`, оставив
текущие настройки. Установленный экземпляр не заменяется этой неподписанной
сборкой. Автообновление остаётся закрытым до проверенного подписанного выпуска
и репетиции возврата.

## Integration prompt (EN)

Add a selectable OpenAI text-to-speech preset in the existing voice settings.
Populate the official API base URL, `gpt-4o-mini-tts`, 24 kHz, and compatible
voice IDs without sending a request. The user must provide their own API key.
For this preset, do not forward proxy-specific extras or a persona voice name
from another provider. Keep custom compatible TTS servers selectable. Test only
with loopback mocks until the user explicitly performs a live API/audio check.
